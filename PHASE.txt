IMPLEMENTATION RULE
--------------------------------------------------------------------------------
Implement phases sequentially. Do not skip a phase unless its verification
requirements are already demonstrably satisfied.

Every phase must:
1. Implement only its defined scope.
2. Preserve existing functionality.
3. Avoid unnecessary UI changes.
4. Run appropriate tests after implementation.
5. Fix failures caused by the phase before declaring completion.
6. Generate and save a .txt implementation/test report in the repository.
7. Leave the project buildable and testable.
8. Clearly state PASS/FAIL for each verification gate.

Recommended report path:
    report/PHASE_<number>_<short_name>_REPORT.txt
