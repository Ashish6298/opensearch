1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 14 of OpenSearch has been successfully implemented and validated.
This phase establishes the first real relevance-ranking engine within
`@opensearch/ranking`. It computes probabilistic BM25 scores with multi-field
weighting (title, headings, description, body), query term coverage multipliers,
exact phrase boosts, URL/domain signals, domain clustering / near-duplicate
penalties, and temporal freshness signals. All calculations are deterministic,
testable, and generate explainable score breakdowns.

--------------------------------------------------------------------------------
2. ARCHITECTURAL & COMPONENT OVERVIEW
--------------------------------------------------------------------------------
A. BM25 Scorer (`packages/ranking/src/scorer/bm25-scorer.ts`):
   - Non-negative smoothed Inverse Document Frequency:
     IDF(t) = ln(1 + (N - n(t) + 0.5) / (n(t) + 0.5))
   - Multi-field term frequency saturation with document length normalization:
     TF_weight(t, d, f) = (TF * (k1 + 1)) / (TF + k1 * (1 - b + b * (len(d, f) / avg_len(f))))
   - Default parameters: k1 = 1.2, b = 0.75.
   - Field weight boosts: Title (3.0x), Headings (2.0x), Description (1.5x), Body (1.0x).

B. Default Ranking Engine (`packages/ranking/src/scorer/ranking-engine.ts`):
   - Signal combination: (BM25 * fullMatchBoost * phraseMatchBoost) + urlMatchBonus + freshnessBonus.
   - Exact Quoted Phrase Boost (1.5x multiplier when phrases occur in adjacent token positions).
   - Full Query Coverage Boost (1.25x multiplier when all query terms match).
   - URL & Hostname Match Bonus (+0.35 additive score per matching slug/host token).
   - Domain Clustering & Near-Duplicate Penalty (0.8x exponential dampening per secondary doc from same domain/title).
   - Freshness Signal (linear temporal decay from 1.0 down to 0.0 over 30 days).
   - Deterministic tie-breaking (primary: score descending, secondary: documentId ascending).
   - Comprehensive score explanations (`ScoreExplanation`) for transparent auditing.

C. Factory & Export Root (`packages/ranking/src/index.ts`):
   - Clean public API exporting `createRankingEngine`, `BM25Scorer`, and associated types.
