## ARCHITECTURAL DESIGN & INTEGRATION

1. `packages/indexer/src/index/index-types.ts`
   - `Posting`: documentId, termFrequency, fieldTermFrequencies (`title`, `headings`, `description`, `body`), fieldPositions
   - `PostingList`: term, documentFrequency, postings map
   - `IndexedDocumentMeta`: documentId, url, urlHash, title, language, totalTerms, fieldLengths, indexedAt
   - `IndexStats`: totalDocuments, totalTerms, totalPostings, avgDocumentLength, avgFieldLengths, lastUpdatedAt
   - `SerializedIndexPayload`: versioned disk payload schema
   - `InvertedIndex`: primary index contract

2. `packages/indexer/src/index/inverted-index.ts`
   - `MemoryInvertedIndex`: implements `InvertedIndex`
     • Dictionary indexing & term frequency aggregation
     • Pruning empty terms upon document deletion
     • Document length metadata calculation for BM25 normalization
     • Atomic temp file writes on `save`
     • Safe deserialization on `load`

3. `packages/indexer/src/index/index-factory.ts`
   - `createInvertedIndex`: factory returning `InvertedIndex` instance

4. `packages/indexer/src/index.ts`
   - Re-exports Phase 10 types, MemoryInvertedIndex, and createInvertedIndex
