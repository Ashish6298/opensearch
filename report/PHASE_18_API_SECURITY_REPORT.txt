2. IMPLEMENTATION SUMMARY
--------------------------------------------------------------------------------
(A) In-Memory Rate Limiting (`apps/api/src/rate-limiter.ts` & `middlewares.ts`):
    - Sliding-window counter tracking client requests per IP address.
    - Zero external database dependencies, minimal memory footprint.
    - Configurable requests per window (`rateLimitPerMinute`, default: 60/min).
    - Standard response headers:
      * X-RateLimit-Limit: configured maximum requests per window
      * X-RateLimit-Remaining: remaining tokens for client in current window
      * X-RateLimit-Reset: Unix epoch second when current window resets
    - Rejection behavior: HTTP 429 Too Many Requests with `Retry-After: <seconds>`.
    - Automated periodic background cleanup of expired client buckets to prevent memory leaks.

(B) Request Timeout Controls (`apps/api/src/middlewares.ts`):
    - Enforces configured `searchTimeoutMs` (default: 5000ms / max: 10000ms).
    - Races request handling against timer; triggers clean abort with HTTP 504 Gateway Timeout
      and standard `TimeoutError` payload (`REQUEST_TIMEOUT`).

(C) Request Size & Query Length Limits:
    - Payload body limit: 64KB (`API_LIMITS.DEFAULT_BODY_LIMIT_BYTES`), rejecting oversized
      POST payloads with HTTP 413 Payload Too Large (`PAYLOAD_TOO_LARGE`).
    - Query character limit: 200 characters (`SEARCH_LIMITS.MAX_QUERY_LENGTH`), rejecting
      excessively long search queries with HTTP 400 Bad Request (`QUERY_TOO_LONG`).

(D) Defensive Security Headers Suite (`apps/api/src/middlewares.ts`):
    - `X-Content-Type-Options: nosniff` (prevents MIME type sniffing)
    - `X-Frame-Options: DENY` (clickjacking protection)
    - `X-XSS-Protection: 1; mode=block` (legacy XSS filter trigger)
    - `Referrer-Policy: strict-origin-when-cross-origin`
    - `Content-Security-Policy: default-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`

(E) Strict CORS Policy & Preflight:
    - Configurable allowed origin (e.g. `http://localhost:5173` or environment-specified origin).
    - OPTIONS preflight handler responding with HTTP 204 No Content, `Access-Control-Allow-Methods`,
      `Access-Control-Allow-Headers`, and `Access-Control-Max-Age: 86400`.

(F) Safe Error Responses & Secret Masking:
    - Guaranteed zero leak of call stack traces, internal file paths, or credentials.
    - Centralized formatting into typed `SafeErrorResponse` with timestamp, status, category,
      and sanitized user-facing error message.

(G) Privacy-Minimizing Request Logging:
    - Client IP address anonymization (`anonymizeIp`):
      * IPv4: masks host octet (`192.168.1.42` -> `192.168.1.0`)
      * IPv6: masks interface host bits (`2001:db8:85a3::8a2e:370:7334` -> `2001:db8:85a3::`)
    - Redaction of sensitive headers and parameters (`Authorization`, `Cookie`, tokens).
