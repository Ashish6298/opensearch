2. TASKS ACCOMPLISHED & ARCHITECTURAL HIGHLIGHTS
------------------------------------------------
[x] Request Inventory & Data-Flow Taxonomy:
    - Created typed data-flow taxonomy in `@opensearch/shared` (`packages/shared/src/privacy/network-audit.ts`).
    - Inventories all request categories:
      * Search API (`/api/v1/search`)
      * Frontend Shell & Assets (`/`, `/app.js`, `/style.css`, `/sw.js`)
      * Providers (`en.wikipedia.org`, `commons.wikimedia.org`, `hn.algolia.com`, Local Index)
      * Suggestions (Internal Prefix Trie)
      * Multimedia Thumbnails (`upload.wikimedia.org`)
      * System Typography (Local OS font stack)
      * Third-Party Scripts, Analytics, Error Reporting (Disabled by default)
      * Outbound Destination Links (User-initiated clicks)

[x] Disambiguation of Browser-to-Host vs Host-to-Provider Traffic:
    - Browser-to-Host: Receives search query (`q`) and client IP. Client IP is masked
      immediately in memory to IPv4 /24 or IPv6 /48 before logging. Zero cookies issued.
    - Host-to-Provider: Server-side API dispatches from host to providers. Provider sees
      only the OpenSearch server IP and User-Agent. Client IP is never forwarded.
    - Browser-to-Third-Party: Image thumbnails and destination link clicks. Thumbnail
      loads enforce `referrerpolicy="no-referrer"`. Outbound links enforce `rel="noopener noreferrer"`.
    - Internal: Local Inverted Index and Prefix Trie execute completely in-memory with
      zero network egress.

[x] Removal of Unnecessary Analytics & Scripts by Default:
    - Zero third-party scripts (no CDNs, unpkg, cdnjs, etc.).
    - Zero analytics pixels (no Google Analytics, Meta Pixel, Hotjar, Segment).
    - Zero external crash reporters (no Sentry, Datadog APM).
    - Hardened Content-Security-Policy (CSP) headers served on all web responses:
      `default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https://upload.wikimedia.org https://commons.wikimedia.org; connect-src 'self' http://localhost:* http://127.0.0.1:* https:; font-src 'self' data:; object-src 'none'; base-uri 'self'; form-action 'self'; frame-ancestors 'none';`

[x] Referrer-Policy Configuration & Isolation:
    - WebServer and API middlewares emit `Referrer-Policy: strict-origin-when-cross-origin`.
    - HTML shell embeds `<meta name="referrer" content="strict-origin-when-cross-origin">`.
    - Multimedia image cards enforce `referrerpolicy="no-referrer"`.
    - Result anchors enforce `rel="noopener noreferrer"`.

[x] Prevention of Query-Bearing URLs on Unrelated Origins:
    - User queries are sent solely to `/api/v1/search`.
    - Implemented `isQueryBearingUrlLeaked()` utility to verify that external destination
      URLs do not inadvertently receive raw search terms as query parameters.

[x] Comprehensive Audit Documentation:
    - Published canonical specification: `docs/network-and-data-flow-audit.md`.
