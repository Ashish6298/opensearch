1. EXECUTIVE SUMMARY
--------------------
Phase 91 implements a standardized, deterministic Information Retrieval (IR)
evaluation metrics engine for OpenSearch (`@opensearch/ranking`), expanding
Milestone 32 ("Search Quality Lab").

Key Accomplishments:
1. Core Standard IR Metrics:
   - Normalized Discounted Cumulative Gain (nDCG@k):
     * Supports both exponential gain ((2^g - 1) / log2(i+1), TREC standard)
       and linear gain (g / log2(i+1)).
     * Dynamic IDCG calculation based on sorting ground-truth judgments.
     * Safely returns 0.0 when IDCG is 0.0 without division-by-zero errors.
   - Mean Reciprocal Rank (MRR):
     * Computes reciprocal rank 1 / rank of first relevant retrieved item.
     * Returns 0.0 if no relevant items are retrieved within cutoff k.
   - Precision@k:
     * Evaluates fraction of top-k retrieved items meeting binary relevance threshold.
     * Correctly handles lists smaller than k by dividing by k.
   - Recall@k:
     * Evaluates retrieved relevant count over total relevant items in ground truth pool.
     * Respects configurable noRelevantDocsPolicy when total relevant count is 0.
   - Mean Average Precision (MAP@k):
     * Evaluates precision at every relevant rank normalized by min(totalRelevant, k).
2. Explicit Policies for Edge Cases:
   - Treatment of Missing Judgments (Unjudged Documents):
     * 'zero' (default): assigns grade 0, penalizing retrieval of unverified documents.
     * 'ignore': omits unjudged documents from the ranked list before evaluation.
     * 'defaultGrade': assigns an explicit fallback grade (e.g., 0 or 1).
   - Treatment of Queries with Zero Relevant Documents:
     * 'zero' (default): returns 0.0 for recall, precision, and average precision.
     * 'one': returns 1.0 (vacuous truth, zero false positives).
     * 'ignore': excludes zero-ground-truth queries from macro-averages in evaluateQuerySet.
3. Deterministic Tie-Breaking & Consistency:
   - When candidate documents have identical scores, ties are deterministically
     broken using lexicographical document ID ascending ('docIdAsc').
   - Ground truth sorting for IDCG breaks identical-grade ties using docId ascending.
   - Guarantees 100% reproducible results across runs, node environments, and platforms.
4. Hand-Calculated Fixtures & Verification:
   - Pencil-and-paper mathematical fixtures verified with 5-decimal precision:
     * Fixture A (4 docs, graded 3, 2, 1, 0, retrieved in non-optimal order):
       DCG@4 = 7.84718, IDCG@4 = 9.39279, nDCG@4 = 0.83545, P@4 = 0.75, R@4 = 1.0,
       RR = 1.0, AP@4 = 0.91667.
     * Fixture B (Perfect order): nDCG = 1.0, MRR = 1.0, MAP = 1.0.
     * Fixture C (All irrelevant): nDCG = 0.0, MRR = 0.0, MAP = 0.0.
     * Fixture D (Linear gain formulation): verified exact manual calculation.
5. Aggregate Multi-Query Evaluation (`evaluateQuerySet`):
   - Computes macro-averaged meanNDCG, MRR, MAP, meanPrecision, meanRecall.
   - Automatically computes per-category breakdown summaries across the 5 categories
     (everyday, education, programming, research, ambiguous).

All 822 automated tests across 76 test suites in the OpenSearch monorepo pass cleanly
with a 100% pass rate. TypeScript composite compilation (`tsc -b`) succeeds with zero errors.
