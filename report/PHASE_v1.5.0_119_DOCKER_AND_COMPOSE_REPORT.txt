1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 119 delivers the official, hardened, production-grade containerization
for OpenSearch Web, implementing:

- Multi-Stage Dockerfile (node:20-alpine):
  * Stage 1 (builder): Caches dependency manifests, performs clean reproducible
    installs (npm ci), builds TypeScript composite workspaces, copies web assets,
    and prunes devDependencies (npm prune --omit=dev).
  * Stage 2 (runner): Minimal Alpine runtime footprint with zero development tools.

- Non-Root Security & User Isolation:
  * Dedicated system group and unprivileged user (opensearch:opensearch, UID/GID 1001).
  * User declaration (USER opensearch) enforces zero root execution.

- Explicit Data Volume Durability:
  * VOLUME ["/app/data"] declaration covers /app/data/storage, /app/data/index,
    and /app/data/crawler.
  * Verified that persistent indexes survive container teardown and recreation.

- Native Health Checks & Graceful Termination:
  * Built-in HEALTHCHECK probe querying /health via Node.js 20 native global fetch
    (eliminating curl/wget dependency in the minimal image).
  * STOPSIGNAL SIGTERM with coordinated server draining and persistent storage flush.

- Minimal Docker Compose Specification:
  * Includes ONLY services genuinely required by the application (opensearch).
  * Excludes unnecessary third-party services (zero Redis, zero external databases).
  * Defines named volume opensearch_data, restart policy, health check, and stop signal.

- Zero Baked-In Secrets:
  * Strict .dockerignore exclusions prevent leaking .env, .git, private keys, or credentials.
  * Image operates 100% out-of-the-box on safe defaults without mandatory secrets.
