## ARCHITECTURAL DESIGN & INTEGRATION

1. `packages/crawler/src/orchestrator/orchestrator-types.ts`
   - `CrawlRunOptions`: seeds, maxPages, maxDepth, politenessDelayMs, userAgent, signal
   - `CrawlRunStats`: live tracking of pagesFetched, pagesStored, fetchErrors, robotsDisallowed, linksDiscovered, duplicatesSkipped, queuePending, durationMs
   - `ProcessedPageOutcome`: outcome of single page crawl operation
   - `CrawlSummary`: final run status, statistics snapshot, and completion message
   - `CrawlOrchestrator`: primary contract interface (initialize, addSeeds, start, stop, getStats, close)

2. `packages/crawler/src/orchestrator/crawl-orchestrator.ts`
   - `DefaultCrawlOrchestrator`: full lifecycle crawler implementation:
     • Initializes queue and storage adapters
     • Validates and seeds URLs
     • Enforces robots.txt policy prior to network requests
     • Applies domain-level politeness delays
     • Coordinates HTTP fetch via HttpFetcher
     • Parses clean searchable documents with HtmlParser
     • Persists DocumentRecord, UrlRecord, and CrawlRecord into StorageAdapter
     • Extracts outbound links and recursively queues within maxDepth limits
     • Tracks metrics and handles graceful stopping via AbortController/signal

3. `packages/crawler/src/orchestrator/orchestrator-factory.ts`
   - `createCrawlOrchestrator`: factory creating configured CrawlOrchestrator instances

4. `packages/crawler/src/index.ts`
   - Re-exports Phase 8 orchestrator types, DefaultCrawlOrchestrator, and createCrawlOrchestrator
