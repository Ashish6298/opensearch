## PHASE OBJECTIVE

Convert downloaded raw HTML content into clean, structured, searchable documents
for indexing and outbound link discovery while eliminating noise (scripts, styles,
navigation, headers, footers, comments, and SVGs).

## ARCHITECTURAL DESIGN & INTEGRATION

1. `packages/crawler/src/parser/parser-types.ts`
   - `HeadingItem`: structured level (1-6) and text
   - `ExtractedLink`: rawHref, normalizedUrl, anchorText, isInternal
   - `ExtractedDocument`: documentUrl, canonicalUrl, title, description, headingItems, headings, bodyText, language, outboundLinks, discoveredUrls, textLength
   - `HtmlParserOptions`: configurable length caps and noise filtering options
   - `HtmlParser`: main parser interface

2. `packages/crawler/src/parser/text-cleaner.ts`
   - `decodeHtmlEntities`: converts named and numeric decimal/hex entities
   - `stripHtmlNoiseTags`: eliminates non-content markup
   - `cleanVisibleText`: converts block elements to clean line breaks and normalizes spaces

3. `packages/crawler/src/parser/link-extractor.ts`
   - `extractBaseHref`: parses `<base href="...">`
   - `extractOutboundLinks`: discovers links, resolves relative paths, validates schemes (http/https only), normalizes with Phase 4 normalizer, and deduplicates

4. `packages/crawler/src/parser/html-parser.ts`
   - `DefaultHtmlParser`: implements `HtmlParser` interface

5. `packages/crawler/src/parser/parser-factory.ts`
   - `createHtmlParser`: factory function
