1. SCOPE & OBJECTIVES
--------------------------------------------------------------------------------
Enable 100% mouse-free power-user keyboard navigation across Web and Terminal interfaces:
1. Vim Keyboard Navigation:
   - `j` / `↓` — Move highlight down across search result cards.
   - `k` / `↑` — Move highlight up across search result cards.
   - `Enter` / `o` — Open currently highlighted result in new browser tab.
   - `c` — Copy selected search result URL to clipboard with a11y notification.
   - `r` / `v` — Toggle Reader Mode / expanded snippet view.
   - `/` — Focus search prompt and select query string.
   - `Escape` — Clear selection, dismiss autocomplete, or close modals.
   - `t` — Cycle retro terminal color themes.
   - `?` — Toggle keyboard navigation cheatsheet modal.
2. Input Guarding:
   - All hotkeys strictly suppressed while user is actively typing in the search box or input fields.
