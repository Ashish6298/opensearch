1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 43 implements a self-contained, zero-dependency developer platform for OpenSearch.
It introduces an OpenAPI 3.1.0 JSON specification generator and an interactive, terminal-styled
documentation UI at `/docs`.

Developers can inspect standard OpenAPI schemas, test live queries directly within an in-browser
"Try It" sandbox with real-time response latency and status code feedback, and copy dynamic code
snippets across 5 languages (cURL, JavaScript, Python, Go, Rust). The documentation is completely
offline-capable and self-hosted with zero external CDN dependencies, adhering strictly to OpenSearch's
Zero-Tracking and Data-Minimization guarantees.

2. KEY DELIVERABLES & ARCHITECTURAL IMPLEMENTATIONS
--------------------------------------------------------------------------------
A. OpenAPI 3.1.0 JSON Spec Generator (apps/api/src/openapi-spec.ts)
   - Exposes comprehensive OpenAPI 3.1.0 document at `GET /api/v1/openapi.json` and `GET /openapi.json`.
   - Complete endpoint coverage:
     * `GET /api/v1/search` & `POST /api/v1/search`: Query parsing, parameters (`q`, `page`, `limit`,
       `category`, `domain`, `site`, `filetype`), instant answers, bangs, did you mean, pagination.
     * `GET /api/v1/suggest`: Prefix autocompletion and term suggestions.
     * `GET /health`: Comprehensive cluster diagnostics, memory metrics, and document counts.
     * `GET /api/v1/status`: Lightweight system health and uptime overview.
     * `GET /api/v1/openapi.json`: OpenAPI schema self-discovery.
   - Structured JSON schemas in `components.schemas` (`SearchApiResponse`, `SearchResultItem`,
     `InstantAnswerResult`, `BangShortcutResult`, `TypoSuggestion`, `PaginationMeta`,
     `SuggestApiResponse`, `HealthCheckResponse`, `ErrorResponse`).

B. Interactive Zero-Dependency Documentation UI (apps/api/src/docs-html.ts)
   - Fast, lightweight semantic HTML5/CSS/JS interface hosted at `GET /docs`.
   - **Interactive "Try It" Sandbox**:
     * Live parameter form (`q`, `page`, `limit`, `domain`, `category`).
     * In-browser `fetch()` execution against live cluster endpoints.
     * Real-time response inspection with status badge (`200 OK`, `400 Bad Request`, `429 Too Many Requests`),
       roundtrip latency timing (`X ms`), payload size indicators, and formatted JSON viewer.
   - **Copy-Ready Multi-Language Code Snippets**:
     * Dynamically reactive code generation for:
       - **cURL (bash)**
       - **JavaScript (fetch / Node.js)**
       - **Python (requests / urllib)**
       - **Go (net/http)**
       - **Rust (reqwest)**
     * One-click copy-to-clipboard functionality with visual feedback.
   - **Comprehensive Status Code & Error Reference**:
     * Status codes 200, 400, 429, 500 reference table with resolution steps.

C. Unified Routing Across Node & Vercel Environments
   - Registered `/docs`, `/api/v1/openapi.json`, and `/openapi.json` in:
     * `@opensearch/api` (`apps/api/src/server.ts` & `apps/api/src/routes.ts`)
     * `@opensearch/web` (`apps/web/src/server.ts` & `apps/web/src/html-template.ts`)
     * Vercel serverless dispatch (`api/index.ts`)
