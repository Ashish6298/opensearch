1. EXECUTIVE SUMMARY & OBJECTIVES
--------------------------------------------------------------------------------
Phase 109 implements a standards-compliant Model Context Protocol (MCP 2024-11-05)
server for OpenSearch, enabling safe, privacy-preserving AI coding agent and
desktop assistant integration:
- Optional MCP Server: Reusable `OpenSearchMcpServer` supporting both standard I/O
  (`runStdioMcpServer`) for CLI/desktop AI agents (Claude Desktop, Antigravity) and
  HTTP/SSE JSON-RPC 2.0 endpoints (`POST /api/v1/mcp` and `GET /api/v1/mcp/sse`).
- Reused Core Abstractions: Integrated directly with `@opensearch/ranking` and
  `@opensearch/indexer` (query parser, BM25 ranking, candidate retriever, result
  generator, and deterministic Quick Answer engine).
- Narrow, Documented Tools:
  * `search`: Lexical search with strict input validation, provenance disclosure,
    and verifiable Privacy Receipt summary.
  * `quick_answer`: Deterministic extractive answer with cited sources; refuses to
    hallucinate when evidence is insufficient.
  * `get_status`: Engine health, document/vocabulary counts, active privacy mode.
  * `get_privacy_policy`: OpenSearch zero-tracking, zero-cookie, zero-profiling policy.
- Strict Schemas & Boundaries:
  * Query length limit: strictly bounded to 200 characters.
  * Result limits: strictly bounded to 20 results (default 5).
  * Input parameter types validated predictably.
- Server-Side Local-Only Mode Enforcement:
  * When `isLocalOnly: true` is configured, client attempts to pass `mode: "standard"`
    are strictly constrained to local search; zero outbound requests are dispatched.
- Security Defense Against Dangerous Capabilities:
  * Blocked shell execution (`exec`, `bash`, `cmd`, `shell`, `system`).
  * Blocked filesystem reading/writing (`fs`, `readFile`, `writeFile`, `read_file`).
  * Blocked arbitrary URL fetching (`fetch`, `curl`, `downloadUrl`, `http_request`).
  * Blocked crawler administration (`crawl`, `crawlStart`, `manageSeeds`).
  * Blocked secrets and credential access (`get_secret`, `credentials`, `read_env`).
- Standard Mode Disclosure:
  * In `initialize` instructions and `search` tool output, explicitly discloses that
    standard mode may query upstream providers (Wikimedia, etc.) with strict IP
    shielding and zero query logging.
- Cancellation Support:
  * Handles MCP `notifications/cancelled` by calling `AbortController.abort()`
    on active requests.
- Minimal Client Example:
  * Created `examples/mcp-client.ts` demonstrating handshake, tool discovery, search,
    status query, and security rejection.
- Disablement Guarantee:
  * Verified that configuring `enableMcp: false` disables MCP endpoints (HTTP 503)
    while core search endpoints operate with 100% functionality and zero impact.

   - `mcp-types.ts`: Protocol definitions, error codes, JSON-RPC 2.0 interfaces,
