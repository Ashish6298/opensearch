1. IMPLEMENTATION SUMMARY
--------------------------------------------------------------------------------
Phase 38 implements zero-click instant answers for arithmetic calculations,
unit/epoch/color conversions, and DuckDuckGo-style `!bang` shortcuts for quick developer redirects
with zero external dependencies and guaranteed safety (strictly avoiding `eval()`):

1. Bang Command Registry & Shortcut Evaluator (@opensearch/ranking & @opensearch/shared):
   - Created `packages/ranking/src/answers/bang-registry.ts`:
     * Catalog of 60+ curated developer and research bangs (`!gh`, `!npm`, `!mdn`, `!w`, `!so`, `!caniuse`, `!rust`, `!pypi`, `!cargo`, `!arxiv`, `!cve`, etc.).
     * Prefix and suffix matching with parameter extraction and URL template expansion.
     * Index lookup table for sub-millisecond evaluation (< 0.05ms).
   - Unit tests in `packages/ranking/tests/instant-answers.test.ts` (17/17 passed).

2. Safe Mathematical Expression Evaluator (@opensearch/ranking):
   - Created `packages/ranking/src/answers/math-evaluator.ts`:
     * Zero-dependency recursive descent AST parser and evaluator (no `eval()` or `Function()`).
     * Supports addition, subtraction, multiplication, division, exponentiation (`^` and `**`), modulo (`%`), and percentages (`X% of Y`).
     * Parentheses nesting and operator precedence evaluation.
     * Standard math functions (`sqrt`, `abs`, `round`, `floor`, `ceil`, `log`, `ln`, `sin`, `cos`, `tan`) and constants (`pi`, `e`).
     * Strict guards rejecting invalid, non-math, division-by-zero, or malicious script inputs.

3. Direct Conversions Engine (@opensearch/ranking):
   - Created `packages/ranking/src/answers/conversion-evaluator.ts`:
     * Unix Epoch & Timestamp converter (seconds/milliseconds to UTC ISO, formatted date, relative delta).
     * Color code converter (HEX, RGB, HSL conversions with CSS color preview values).
     * Physical and digital unit conversions (Temperature, Length, Weight, Digital Storage).

4. API & Master Orchestration (@opensearch/api & @opensearch/ranking):
   - Created `packages/ranking/src/answers/instant-answer-engine.ts` coordinating all answer categories.
   - Updated `apps/api/src/types.ts` and `apps/api/src/routes.ts`:
     * Added `instantAnswer?: InstantAnswerPayload` and `bang?: BangResult` to `SearchApiResponse`.
     * API integration tests in `apps/api/tests/api.test.ts` (27/27 passed).

5. Web Frontend UI Card & Terminal Theme (@opensearch/web):
   - Added `#instant-answer-card` in `apps/web/src/html-template.ts`.
   - Designed `.instant-answer-card` with phosphor-green accents, badges (`[calculator]`, `[epoch-converter]`, `[color-converter]`, `[unit-converter]`, `[bang-redirect]`), color preview swatches, and direct redirect buttons in `apps/web/src/style.css` and `apps/web/src/app.js`.
