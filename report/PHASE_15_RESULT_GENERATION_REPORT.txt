2. ARCHITECTURAL & COMPONENT OVERVIEW
--------------------------------------------------------------------------------
A. HTML & Text Escaper (`packages/ranking/src/results/html-escaper.ts`):
   - Comprehensive XSS character escaping (&, <, >, ", ', `).
   - Entity unescaping utility.
   - Tag stripping utility (`stripHtmlTags`) removing raw HTML while preserving text.

B. Snippet Generator (`packages/ranking/src/results/snippet-generator.ts`):
   - Sliding-window keyword density cluster locator.
   - Word boundary alignment preventing chopped mid-word tokens.
   - Truncation boundaries with clean ellipsis formatting ('… snippet …').
   - Safe `<mark>` tag query term highlight injection performed after HTML escaping.
   - Robust fallback text on empty/missing page bodies.

C. Default Result Generator (`packages/ranking/src/results/result-generator.ts`):
   - Full orchestration: generates `SearchResultSet` from `ScoredDocument[]`.
   - Title fallbacks: gracefully derives title from URL path slug or domain when missing.
   - Display URLs: formats breadcrumb hierarchies (`domain.com › section › page`).
   - Domain/Host extraction and language preservation.
   - Pagination calculation (`computePagination`): exact totalPages, hasNextPage, hasPrevPage,
     nextPage, prevPage, and slice indices.

D. Factory & Export Root (`packages/ranking/src/index.ts`):
   - Clean public API exposing `createResultGenerator`, `SnippetGenerator`, `escapeHtml`,
     `stripHtmlTags`, and all associated domain types.
