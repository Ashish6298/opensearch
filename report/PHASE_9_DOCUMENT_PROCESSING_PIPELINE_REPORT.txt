## ARCHITECTURAL DESIGN & INTEGRATION

1. `packages/indexer/src/pipeline/pipeline-types.ts`
   - `TokenPosition`, `Token`: captures normalized term, sequential position, startOffset, and endOffset
   - `FieldWeightConfig`: typed weight map for title, headings, description, and body fields
   - `ProcessedField`: field name, weight, total token count, token array, and term frequencies map
   - `DocumentTermSummary`: aggregated term statistics across all document fields
   - `ProcessedDocument`: full structured representation ready for index insertion
   - `DocumentProcessor`: primary pipeline interface (process, tokenizeText, normalizeTerm)

2. `packages/indexer/src/pipeline/normalizer.ts`
   - `normalizeText`: applies Unicode normalization, control char stripping, accent folding, and case folding
   - `foldDiacritics`: strips combining diacritical marks in range \u0300-\u036f
   - `stripPunctuation`: replaces punctuation and symbols with spaces

3. `packages/indexer/src/pipeline/stop-words.ts`
   - `DEFAULT_STOP_WORDS`: immutable Set of standard English stop words
   - `isStopWord`: constant-time lookup helper supporting custom word sets

4. `packages/indexer/src/pipeline/tokenizer.ts`
   - `tokenize`: extracts tokens via Unicode word boundary regex (`[\p{L}\p{N}]+`), computes offsets, applies length/stop-word filters

5. `packages/indexer/src/pipeline/field-weights.ts`
   - `DEFAULT_FIELD_WEIGHTS` and `getFieldWeight` helper

6. `packages/indexer/src/pipeline/document-processor.ts`
   - `DefaultDocumentProcessor`: transforms `DocumentRecord` or raw document inputs into `ProcessedDocument`
   - `createDocumentProcessor`: factory creating configured processor instances

7. `packages/indexer/src/index.ts`
   - Re-exports all pipeline types, functions, classes, and factories
