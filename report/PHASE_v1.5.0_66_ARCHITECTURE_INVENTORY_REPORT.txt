2. DETAILED ARCHITECTURAL DISCOVERIES
--------------------------------------------------------------------------------

1. PageRank Reality:
   - AuthorityScorer (packages/ranking/src/scorer/authority-scorer.ts) has a score blending
     formula that accepts an optional pageRank argument with a default value of 0.5.
   - RankingEngine (packages/ranking/src/scorer/ranking-engine.ts) does NOT calculate or pass
     PageRank from any link-graph analysis. It uses multi-field BM25, freshness decay, and
     domain authority heuristics. PageRank is effectively an uncalculated placeholder.

2. VByte Compression Reality:
   - VByteCompressor is implemented in packages/storage/src/compression/vbyte-compression.ts
     with Delta gap encoding and 7-bit continuation byte packing into native Uint8Array.
   - However, MemoryInvertedIndex.save() in packages/indexer/src/index/inverted-index.ts serializes
     the index directly to uncompressed JSON (index-data.json). The VByte compressor is not yet
     integrated into the primary index persistence pipeline.

3. Rate Limiting & Storage Dependencies:
   - Rate limiting in apps/api/src/rate-limiter.ts (MemoryRateLimiter) and packages/crawler
     (SlidingWindowRateLimiter) runs entirely in process memory (JavaScript Maps) with no disk persistence.
   - Storage in packages/storage/src/adapters/json-adapter.ts writes atomic JSON files via .tmp
     write + rename, maintaining an in-memory cache for reads.

4. Security & Privacy Mechanisms:
   - SSRF protection in packages/crawler/src/fetcher/ssrf-guard.ts validates IP ranges syntactically
     and resolves DNS hostnames asynchronously, re-checking on every redirect.
   - IP anonymization in packages/shared/src/privacy/index.ts masks IPv4 to /24 and IPv6 to /48
     before request logging in apps/api/src/middlewares.ts.
   - Zero cookies, zero local storage tracking, zero external telemetry.
