1. EXECUTIVE SUMMARY
--------------------
Phase 93 implements automated ranking regression gating and category trade-off
review detection for OpenSearch (`@opensearch/ranking`), concluding Milestone 32
("Search Quality Lab").

Key Accomplishments:
1. Formal Regression Thresholds Defined (`RegressionThresholds`):
   - Defined strict gating ceilings in `packages/ranking/src/evaluation/regression-types.ts`:
     * `maxAggregateNdcgDrop: 0.01` (1.0% maximum allowable drop in macro-averaged nDCG)
     * `maxAggregateMrrDrop: 0.02` (2.0% maximum allowable drop in MRR)
     * `maxIndividualQueryNdcgDrop: 0.10` (hard ceiling for any single query)
     * `maxCategoryNdcgDrop: 0.03` (maximum drop in any semantic category)
     * `categoryTradeoffDropThreshold: 0.02` (category drop triggering trade-off review)
     * `maxAllowedRegressionRatio: 0.20` (at most 20% of queries may exhibit negative shifts)
2. Anti-Hiding Principle: Regressions Cannot Be Hidden Behind Single Aggregate Scores:
   - Verifies that even when global macro-averaged nDCG rises (e.g. +0.02 across 9 queries),
     a single query suffering a severe drop (e.g. -0.25) is detected, classified as
     `SEVERE_REGRESSION`, and causes the regression gate to fail (`passed: false`).
   - Query classifications:
     * `severe`: $\Delta \text{nDCG} < -0.10$ (blocks gate)
     * `moderate`: $-0.10 \le \Delta \text{nDCG} < -0.05$
     * `minor`: $-0.05 \le \Delta \text{nDCG} < -0.001$
     * `none`: $\Delta \text{nDCG} \ge -0.001$ (neutral or improved)
3. Category Trade-Off Review Protocol:
   - Evaluates whether one category (e.g. `programming`) improves while another
     (e.g. `everyday` or `education`) degrades.
   - When a category drop exceeds 0.02 while another gains > 0.01, the gate flags:
     `requiresReview: true`, generating an actionable engineering review record.
4. Lightweight Deterministic Evaluation in Continuous Integration (CI):
   - `runCiRegressionGate()`: executes using the curated, deterministic `CI_JUDGED_DATASET`
     (20 queries, 63 graded judgments).
   - Runtime: < 30ms (tested 26ms).
   - 100% deterministic with 0 network calls and 0 flake risk.
5. Zero Private User Queries in CI Artifacts:
   - Active regex scanning asserts zero email addresses, IP addresses, session tokens,
     or live user query logs exist in evaluation datasets or regression logs.
   - `privacyVerified: true` strictly enforced.

All 843 automated tests across 79 test suites in the OpenSearch monorepo pass cleanly
with a 100% pass rate. TypeScript composite compilation (`tsc -b`) succeeds with zero errors.
