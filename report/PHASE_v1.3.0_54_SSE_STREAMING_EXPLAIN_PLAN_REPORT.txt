1. SCOPE & OBJECTIVE
--------------------------------------------------------------------------------
Provide a real-time streaming search API (`/api/v1/search/stream`) using SSE, alongside
an in-depth Query Explain Plan debugger (`--explain` / `/docs` inspector).

2. IMPLEMENTATION SUMMARY
--------------------------------------------------------------------------------
- SSE Streaming Search Endpoint (@opensearch/api/src/routes.ts & server.ts):
  * Route: `GET /api/v1/search/stream?q=<query>&limit=<limit>`
  * Sets native SSE headers (`Content-Type: text/event-stream; charset=utf-8`, `Cache-Control: no-cache`, `Connection: keep-alive`).
  * Emits progressive event stream:
    - `event: answer` (instant calculations, conversions, knowledge cards, cheatsheets, or bangs emitted immediately)
    - `event: results` (scored document items and metadata)
    - `event: done` (search latency metrics, candidate counts, completion timestamp)
  * Clean socket connection closing upon client abort with zero memory leaks.
- Query Explain Plan Inspector (@opensearch/api/src/routes.ts & types.ts):
  * Query parameter `explain=true` attached to `GET /api/v1/search`.
  * Returns detailed per-result score explanations containing BM25 term scores, coverage multipliers, phrase boosts, freshness bonus, domain authority bonus, and duplicate penalties.
- Terminal CLI Integration (@opensearch/cli/src/cli.ts & formatter.ts):
  * Added `--explain` (`-e`) flag to CLI command parser.
  * Formatted visual score breakdown tree in CLI search results.
- OpenAPI 3.1.0 Documentation Updates (@opensearch/api/src/openapi-spec.ts):
  * Documented `/api/v1/search/stream` endpoint with request parameters and `text/event-stream` schema.
