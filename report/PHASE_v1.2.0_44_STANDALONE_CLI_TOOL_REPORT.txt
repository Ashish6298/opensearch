1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 44 implements a standalone, lightweight command-line interface tool (`@opensearch/cli`,
`npx @opensearch/cli` / `opensearch`) that enables developers to query OpenSearch directly
from bash, zsh, and PowerShell terminal environments.

The CLI tool features a custom zero-dependency argument parser, ANSI color formatting matching
the retro terminal green/cyan matrix theme, standard Unix stdin stream piping support
(`echo "query" | opensearch`), raw machine-readable JSON output (`--json`) for shell pipelines
(`jq`), prefix autocomplete lookups (`--suggest`), and cluster diagnostic health probing
(`--health`).

2. KEY DELIVERABLES & ARCHITECTURAL IMPLEMENTATIONS
--------------------------------------------------------------------------------
A. Package Infrastructure (packages/cli/package.json, packages/cli/tsconfig.json)
   - Created `@opensearch/cli` with binary mapping `bin: { "opensearch": "./dist/bin.js" }`.
   - Native composite TypeScript build configuration referencing `@opensearch/shared`.
   - Executable hashbang entrypoint in `packages/cli/src/bin.ts`.

B. Terminal ANSI Color Formatter (packages/cli/src/formatter.ts)
   - Retro matrix phosphor green (`#22c55e`), cyan links (`#38bdf8`), dimmed snippets (`#8b949e`),
     and distinct instant answer / bang redirect badge styling.
   - Automatic `NO_COLOR` environment variable detection and non-TTY stream detection to cleanly
     omit escape sequences when piped to files or external programs.
   - Layout formatters for search results, instant answers, bangs, did you mean suggestions,
     cluster health metrics, autocomplete suggestions, and terminal ASCII help manuals.

C. Zero-Dependency CLI Engine & Parser (packages/cli/src/cli.ts)
   - Custom argument parser supporting short and long flags:
     * `<query>`: Positional search terms.
     * `-l, --limit <num>`: Result count control.
     * `-p, --page <num>`: Pagination control.
     * `--json`: Outputs raw, parseable JSON payload.
     * `--api <url>`: Configurable target cluster URL (defaults to `OPENSEARCH_API_URL` or `http://localhost:3001`).
     * `-s, --suggest <prefix>`: Fetches prefix autocompletions.
     * `--health`: Diagnostic telemetry probe.
     * `-h, --help`: Usage guide and ASCII logo banner.
     * `-v, --version`: Version string.
   - Stdin reader with timeout guard allowing Unix query piping (`echo "rust" | opensearch`).
   - Resilient HTTP error handling with informative, user-friendly terminal output when cluster
     is unreachable.
