## PHASE OBJECTIVE

Build a secure, reliable HTTP fetcher capable of downloading permitted public
web resources for the crawler while strictly controlling network access and
resource consumption. Implement a strongly typed HTTP fetcher abstraction and
concrete NodeFetcher implementation behind a replaceable HttpFetcher interface;
accept only normalized and validated URLs from Phase 4; validate all redirect targets
against SSRF risks; enforce strict configurable limits for timeouts, redirects,
retries, content-type filtering, and response body size (stream aborted if size
exceeds limit); emit custom User-Agent headers and integrate with the shared
logging and configuration system.
