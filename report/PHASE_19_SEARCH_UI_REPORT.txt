1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Phase 19 initiates Milestone 6 (Public Web Application) by creating a clean,
responsive, zero-tracking, privacy-first public search web interface (`apps/web`).

The implementation adheres to the zero-cost architecture constraint and uses
vanilla HTML5, CSS, and modern browser JavaScript with zero bloated UI library
dependencies. It features semantic structure, ARIA accessibility landmarks,
focus management, a search box with clear and submit triggers, reactive state
containers (home hero, loading skeleton with progress bar, empty state with search
tips, and error state with retry), and an embedded Node.js HTTP `WebServer`.

2. IMPLEMENTATION SUMMARY
--------------------------------------------------------------------------------
(A) HTML Application Shell (`apps/web/src/html-template.ts`):
    - Semantic structure: `<header>`, `<main class="main-content center-mode">`, `<footer>`.
    - ARIA landmarks: `role="search"`, `role="main"`, `role="status"`, `role="alert"`, `aria-live`.
    - Brand title, V1.0.0 badge, privacy pill ("🛡️ Privacy First").
    - Home hero container with search tagline and privacy value propositions:
      * "✓ No Accounts Required"
      * "✓ Zero Tracking & Profiling"
      * "✓ Lexical BM25 Ranking"

(B) Search Box & Controls (`apps/web/src/html-template.ts` & `style.css`):
    - Search input (`type="search"`, `maxlength="200"`, `autocapitalize="off"`, `spellcheck="false"`).
    - Clear input button (`#search-clear-btn`), dynamically visible when text is entered.
    - Submit search button (`#search-submit-btn`) with hover and active states.
    - Focus ring indicators (`:focus-visible`) for keyboard navigation.

(C) Responsive CSS Design System (`apps/web/src/style.css`):
    - Curated color tokens with light and dark mode support (`prefers-color-scheme`).
    - Fluid layout adapting seamlessly to mobile (<640px) and desktop viewports.
    - Skeleton loading animation with shimmer effect and indeterminate progress bar.

(D) Reactive Client-Side Controller (`apps/web/src/app.js`):
    - State transitions: `home` mode (centered hero) -> `results` mode (top aligned).
    - URL query parameter synchronization (`?q=...`) and browser history `popstate` support.
    - Accessible UI state management:
      * Loading state: `#loading-indicator`
      * Empty state: `#empty-state` with query echo and query refinement tips
      * Error state: `#error-state` with error description and `#error-retry-btn`
    - API connection to `@opensearch/api` endpoint.

(E) Embedded WebServer (`apps/web/src/server.ts`):
    - Zero-dependency Node.js HTTP server hosting the search application.
    - Serves `GET /` (HTML shell), `GET /style.css` (stylesheet), `GET /app.js` (script),
      and `GET /health` (JSON status).
    - Injects defensive HTTP security headers (`X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`).
