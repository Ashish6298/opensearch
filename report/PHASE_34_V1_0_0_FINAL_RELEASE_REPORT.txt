1. IMPLEMENTATION & ARCHITECTURE SUMMARY
--------------------------------------------------------------------------------
OpenSearch V1.0.0 is an independent, general-purpose, privacy-first web search engine
designed and built entirely from scratch with zero third-party search APIs, zero
external database licenses, and zero tracking dependencies.

The system is organized into decoupled, composite TypeScript workspaces:
- @opensearch/shared: Domain models, error hierarchies, logging, and configuration
- @opensearch/storage: Durable file-based JSON repository and indexing metadata
- @opensearch/crawler: Polite web crawler with RFC 9309 robots compliance and SSRF guard
- @opensearch/indexer: Document processing, tokenization, text normalization, and inverted index
- @opensearch/ranking: Okapi BM25 relevance ranking, document length normalization, and query cache
- @opensearch/api: HTTP API service with rate limiting, error sanitization, and health metrics
- @opensearch/web: Accessible, responsive semantic HTML/CSS/JS frontend search client

6. KNOWN LIMITATIONS & ACCEPTED SCOPE FOR V1.0.0
--------------------------------------------------------------------------------
- Inverted Index Storage: Optimized in-memory posting list with disk serialization. Very large multi-million page corpora in future milestones will migrate to chunked disk postings (BM25 memory-mapped files).
- Multi-Lingual Stemming: V1.0.0 focuses on English tokenization and Unicode diacritic folding. Lemmatization for CJK/morphological languages is scheduled for V1.1+.
- Image/Media Search: V1.0.0 indexes textual documents; multimedia indexing is planned for future iterations.
