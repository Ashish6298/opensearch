1. OBJECTIVE & SCOPE
--------------------------------------------------------------------------------
Empower power users and terminal purists to navigate, select, preview, and open
search results entirely via keyboard without touching the mouse, keeping the
terminal aesthetic clean, accessible, and responsive.

--------------------------------------------------------------------------------
2. IMPLEMENTATION SUMMARY
--------------------------------------------------------------------------------
A. apps/web/src/app.js:
   - Keyboard Event Manager with non-interfering input detection (disables
     navigation hotkeys when user is actively focused in #search-input or form controls).
   - Keybindings:
     * 'j' / 'ArrowDown': Cycle active selection to next result card (wraps around).
     * 'k' / 'ArrowUp': Cycle active selection to previous result card (wraps around).
     * 'Enter': Opens currently active result card URL in a new browser tab.
     * 'v': Toggles expanded snippet / document details row on the active card.
     * '/': Focuses terminal search input box and selects text for quick replacement.
     * 'Escape': Multi-context dismissal (closes shortcuts modal, closes autocomplete
       dropdown, clears search input, or clears active result highlight).
     * '?': Toggles the keyboard shortcuts cheat-sheet overlay modal.
   - Smooth auto-scrolling (`scrollIntoView({ behavior: 'smooth', block: 'nearest' })`)
     to keep active selected card comfortably in viewport.
   - Live ARIA screen-reader announcements (`announceA11y`) on card selection and modal state.

B. apps/web/src/html-template.ts:
   - Added `#shortcuts-modal` overlay dialog with accessible ARIA semantics (`role="dialog"`,
     `aria-modal="true"`, `aria-labelledby="shortcuts-title"`).
   - Added `shortcuts [?]` interactive footer trigger button for mouse discoverability.
   - Formatted keyboard shortcuts cheat-sheet grid with `<kbd>` key badges.

C. apps/web/src/style.css:
   - `.terminal-result-item.active-item`: Glowing terminal green left-border (`border-left: 3px solid var(--accent-green)`),
     soft backdrop glow (`box-shadow: 0 0 12px rgba(48, 209, 88, 0.15)`), and active index styling.
   - `.result-expanded-details`: High-contrast nested detail card displaying document ID, target URL, and keyboard tips.
   - `.shortcuts-modal-overlay` & `.shortcuts-modal-dialog`: Backdrop blurred retro modal with glowing border and close triggers.
