2. TASKS ACCOMPLISHED
---------------------
[x] Repeatable Ingestion Workflow for Permitted Datasets & APIs:
    - Implemented `packages/indexer/src/corpus/corpus-generator.ts` with a seeded
      pseudorandom generator (Mulberry32) that produces identical datasets given the same seed.
    - Implemented `packages/indexer/src/corpus/corpus-ingestion.ts` to validate document schema,
      verify open license compliance, filter out duplicate URLs and content hashes, and batch-insert
      documents into `StorageAdapter`.
    - Implemented `packages/indexer/src/corpus/demo-corpus.ts` containing a curated offline reference
      corpus of foundational computer science, networking, and search architecture documents.

[x] Controlled Scale Stages (1,000, 10,000, 100,000 docs):
    - Tier 1 ('demo'): 100 to 1,000 documents generated in < 100ms for fast CI and unit tests.
    - Tier 2 ('benchmark'): 10,000 documents with verifiable vocabulary and word distributions.
    - Tier 3 ('large'): Scalable architecture supporting batch/streaming generation of 100,000+
      documents without RAM exhaustion.

[x] Provenance & Metadata Storage:
    - Every document record stores:
      * `canonicalUrl`: Standardized public web URL
      * `urlHash`: 64-character SHA-256 hash for deduplication and joins
      * `source`: Verified provenance identifier (e.g. 'wikimedia-open', 'ietf-rfc', 'mdn-open-docs')
      * `license`: Legally compliant license (e.g. 'CC BY-SA 4.0', 'Public Domain / IETF Trust')
      * `licenseUrl`: Authoritative URL for terms and attribution
      * `acquiredAt`: ISO 8601 acquisition timestamp
      * `contentHash`: SHA-256 hash of normalized body text for near-duplicate detection
      * `tags`, `headings`, `wordCount`, `contentLength`, and `outboundLinks`

[x] Large Downloaded Corpora Kept Outside Git:
    - Enhanced `.gitignore` rules to explicitly ignore `data/`, `data/corpus/`, `*.corpus`,
      `*.dump`, `*.jsonl`, and `*.xml.bz2`.
    - Small demo corpus remains embedded in source for 100% offline CI without repository bloat.

[x] Small Demo Corpus for Offline Development & CI:
    - Verified `getDemoCorpus()` runs completely offline with 0 network calls and 0 API dependencies.

[x] Crawl Permissions and Dataset Terms Compliance:
    - Permitted source registry (`PERMITTED_CORPUS_SOURCES`) enforces licensing attribution and
      rejects documents originating from unverified or restrictive sources.
